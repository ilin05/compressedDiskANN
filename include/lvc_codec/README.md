# Vendored LVC codecs

These files are copied unchanged from the sibling `hnswlib_cpp_py` repository at commit `0040d72`.
The directory layout preserves the relative includes in `hnswlib/compressed_codecs.h`.
The D0 adapter uses the DeXOR, Gorilla, and Elf codecs. The copied codec header also contains
Camel and DeXORPlus, so their source dependencies are included for completeness.

The source repository's Apache 2.0 license is included as `LICENSE`.
